# 19 · D-3 双摄门槛结论（实验性）

| 项 | 值 |
|---|---|
| 决策 | D-3：双摄保持**实验性**，P2 不作为卖点 |
| 日期 | 2026-10-21 |
| 依据 | Top5 决策 D-3：“支持率 ≥40% 才作卖点，否则实验性” |

## 1. 数据

| 项 | 结果 |
|---|---|
| 可测设备 | 仅模拟器 1 台（无 Top20 机型矩阵） |
| 双摄探测 | 逻辑多摄支持、并发组合 1 对（`T0-A1`） |
| PiP 原型 | Camera2 双路 + OpenGL 合成，单 SurfaceView；56fps、thermal=0 |
| 合成证据 | [docs/assets/p2-dual-pip.jpg](./assets/p2-dual-pip.jpg) |
| 编码/推流 | 未接入；MediaCodec/MediaRecorder 单路输出尝试未通过画质/时序验收，已回退 |

## 2. 结论

- 支持率无法达到 ≥40% 的证据门槛（缺 Top20 机型数据）；
- 因此双摄**不进入 P2 GA 卖点/默认能力**，保持“实验性”入口（设置页 PiP 预览）；
- T0-A3 的正式编码接入（单路 H.264 输出/推流）延后到有 D-3 数据与双摄真机后；
- 若后续数据 ≥40%，再按 P2 WBS T0-A3 评估 OpenGL→MediaCodec/GOP 管线接入。

## 3. 影响

| 项 | 影响 |
|---|---|
| P2 G2 | 双摄不作为必过项，但需在验收报告声明“实验性/未达门槛” |
| PRD 双摄卖点 | 不启用；保留实验入口与免责说明 |
| 风险 | R-001 双摄兼容性继续跟踪 |
